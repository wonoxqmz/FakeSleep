假休眠 FakeSleep

电脑在客厅跑着项目，屏幕看着像关机 —— 但远程控制软件仍然看得到完整画面。

当前版本 v1.3.4 · Windows 10/11 · MIT

两个模式

F2

黑屏

所有显示器纯黑，远程端也一起黑。适合「谁都别看见」。

F1

隐私 · 真·纯黑

本机像素级纯黑，远程照常看到桌面、键鼠还能操作。
原理：纯黑遮罩 + 从屏幕捕获里排除。

怎么用

  1. 双击运行，出现小面板
  2. 按 F1 进隐私（本机黑、远程正常），按 F2 进黑屏
  3. 再按一次对应热键，或按 Esc，恢复
  4. 手机远控没有功能键？点面板按钮进入，隐私模式点右上角「恢复 ×」退出

它做了什么

行为说明
阻止系统休眠SetThreadExecutionState，每 25 秒续一次
阻止熄屏 / 屏保叠加 ES_DISPLAY_REQUIRED（可配置关掉更省电）
隐私模式纯黑SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)：遮罩只画在屏幕上，捕获里不存在
远程可操作遮罩设 WS_EX_TRANSPARENT，点击穿透到下层窗口
退出即恢复关程序会清除休眠限制，亮度也一定还原

配置 config.ini

[hotkey]            ; 黑屏热键（默认 F2）
key = F2

[privacy]           ; 隐私热键（默认 F1）
key = F1
method = veil       ; veil = 遮罩排除捕获（推荐）/ ddc = 硬件调光 / both
exit_button = corner; corner = 右上角迷你按钮 / bar = 底部大条 / off = 不显示

[display]
keep_display_on = yes
